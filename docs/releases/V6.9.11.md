# V6.9.11 — Navigation et fiches de lieux

*Date : 06/11/2026*  
*Tag : `v6.9.11` (cible : `main`)*

Quatre propositions gardées pour choisir les destinations plus vite et donner du contexte RP à l'arrivée : les favoris du copilote en tête de sa liste, un point de base pour les pilotes, des zones à vitesse réduite et une fiche par lieu. Tout marche sans rien construire dans Studio. Vérifié par simulation.

### Favoris en tête de liste (1)
- Le **poste du copilote** range maintenant ses favoris (les siens, comme dans le menu T et la tablette) **en tête de la liste**, marqués « ● » et notés « favori ». Les autres lieux gardent leur ordre. La liste se remet en ordre dès qu'un favori est ajouté ou retiré.

### Point de base (8)
- Les pilotes définissent un lieu **« Base »** depuis la tablette (onglet Navigation) : bouton **« ■ DÉFINIR COMME BASE »** sur un lieu, ou **« ■ DÉFINIR LA BASE ICI »** sur la ligne Base, TARDIS posé (pratique sans destination construite). Le même bouton la retire.
- Un raccourci **« Base : X »** apparaît en tête des lieux dans le **menu T**, la **tablette** et le **poste du copilote**. Le copilote peut y voyager, mais seuls les pilotes la définissent.
- Si la base est une destination, le TARDIS suit sa Part (même déplacée) et la fiche du lieu s'affiche. Si la Part disparaît, il va à la position gardée. La base est **sauvegardée** avec le reste.

### Zones à vitesse réduite (16)
- Nouveau sous-dossier **`TARDIS_DESTINATIONS › VITESSE_REDUITE`** : au départ ou à l'arrivée dans une de ses zones (marge de 6 studs, comme `REFUSE` et `SANS_EXPRESS`), seuls le **Classique** et le **Silencieux** sont permis. Urgence, Rapide et Sauvetage deviennent un voyage classique, avec le message « ZONE À VITESSE RÉDUITE : VOYAGE CLASSIQUE » et « Voyage classique imposé » dans la réponse.
- **Une urgence imposée n'est jamais désarmée** : alerte générale, collision, zone `REFUSE` ou urgence lancée par un autre script (saisie, tempête). Le paradoxe (Catastrophe) non plus.
- Les menus affichent le statut **« VITESSE RÉDUITE »** (en ambre) pour ces lieux.

### Fiches de lieux (144)
- Chaque destination peut avoir une **fiche** : attributs **`Description`**, **`Dangers`** et **`NiveauDanger`** (0 à 3) sur sa Part, ou une entrée dans **`Config.FichesLieux`** (l'attribut l'emporte). Textes coupés à 300 caractères.
- À l'arrivée, les joueurs **à bord** voient une **carte de 7 s sous « POSÉ »**, au style « Hologramme de confinement », colorée selon le niveau : vert (sans danger), ambre (prudence), orange (dangereux), rouge (danger extrême). Elle disparaît si le joueur descend ou si le TARDIS repart.
- Le serveur publie la fiche (attribut `FicheLieu`) : le client ne fait que l'afficher.

### Dans Studio (facultatif)
- Créer dans `Workspace › TARDIS_DESTINATIONS` un sous-dossier **`VITESSE_REDUITE`** avec des Parts (destinations ou zones) qui couvrent les lieux concernés. Commun aux trois TARDIS.
- Sur les Parts de destination, en option : attributs texte **`Description`** et **`Dangers`**, attribut nombre **`NiveauDanger`** (0 à 3). Ou remplir `Config.FichesLieux` dans `TardisConfig`.

### Technique
- `TardisConfig` : `Config.Version = "6.9.11"`, `Config.ZoneVitesseReduite`, `Config.FicheLieu` (durée, longueur, niveaux), `Config.FichesLieux` et `Config.ficheLieu(part)`.
- `TardisServeur` : `modeAutorise(mode, position, urgenceImposee)` applique la zone ; `decoller` et `atterrir` transmettent l'urgence imposée ; `atterrir` publie `FicheLieu` et renvoie le mode joué ; `definirBase` (action **`DefinirBase`**, pilotes seulement) ; branche `{ base = true }` dans `resoudreDestination` ; attributs `BaseNom` et `BaseCF` ; base sauvegardée. `VolLibre`, ramassage et pose à la main retirent `FicheLieu`.
- `TardisUI.statutDestination` : statut `VITESSE_REDUITE`. `TardisCommandes.donnees` : choix « base ».
- Menu T, tablette (`Navigation`, `Etat`, `Construction`, `Journal`, `Volet`) et `TardisExtrasClient › Copilote` : entrée Base ; `Signalisation` : carte de la fiche.

### Simulations
- `outils/simulation/sim_v6911.py` : **96 tests sur 96** (le vrai `Config.ficheLieu` ; le vrai `modeAutorise` dans et hors zone, urgence imposée ; `decoller` et `atterrir` ; `publierFicheLieu` en JSON ; les vrais `definirBase` et `resoudreDestination` : destination, ici, retrait, refus, Part déplacée ou disparue ; `UI.statutDestination` ; `Commandes.donnees` ; le vrai tri des favoris du copilote ; la carte de `Signalisation` image par image). `sim_v69101`, `sim_v69102`, `sim_v69104`, `sim_v69105` et `sim_v69109` acceptent les versions suivantes ; `sim_v698` accepte les tests déjà notés réussis ; `sim_v69106` connaît la ligne Base de la tablette. Toutes passent : **1 305 vérifications**, analyse statique : 0 remarque.
