# V6.9.6 — Simulations sans Roblox, intercom en pause

*Date : 02/11/2026*  
*Tag : `v6.9.6` (cible : `main`)*

### 1. Simulations (`outils/simulation`)
Je n'ai pas Roblox : ces outils vérifient le code avant que tu l'installes. Lancer : `sh outils/simulation/lancer.sh`.
- **Analyse statique** des 50 scripts : variables inconnues, fonctions appelées avant d'être déclarées, actions envoyées sans serveur pour les traiter, réglages `Config.X` inexistants, attributs jamais écrits, contexte des modules, pont interne. **Résultat : 0 remarque.**
- **Exécution réelle** du code, avec un petit interpréteur Luau écrit en Python et de faux objets Roblox (DataStore avec pannes simulées, temps virtuel pour `task.wait`) :
  - configuration : **68 tests sur 68** (modes, durées, souffles entre 0 et 1, maintenance, pilotes, équipes, retraits de la V6.9.5) ;
  - sauvegarde : enveloppe versionnée, migration sans toucher l'ancien magasin, 2 pannes puis réussite, 3 pannes = pas d'écrasement ;
  - commandes de voyage : vortex de 10 s puis REMAT automatique (une seule), REMAT manuelle, appui pendant le compte à rebours, paradoxe et sa confirmation de 15 s, téléportation de poche, petit TARDIS, interrupteurs de mode exclusifs (**39 sur 39** avec la sauvegarde) ;
  - supervision : rôle de technicien qui suit l'équipe C.T.A.T., balise `/tardis help`, plus aucune commande du staff (**15 sur 15**).
- Limites : la physique, l'affichage, les effets et le réseau ne sont pas simulés. Les tests en jeu restent nécessaires.

### 2. Intercom en pause
- Le bloc `Config.Intercom` est **en commentaire** : plus d'annonce « faille spatio-temporelle » ni de rappel aux pilotes. Sans ce bloc, `TardisExtras` et `TardisPontFondation` considèrent l'intercom comme coupé. Pour le réactiver : voir [RAPPELS.md](https://github.com/StudioRbx/T.A.R.D.I.S/blob/main/docs/RAPPELS.md).
