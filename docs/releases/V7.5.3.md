# V7.5.3 — Régénération : poses du corps

*Date : 07/11/2026*  
*Tag : `v7.5.3` (cible : `main`)*

Troisième lot de la V7.5 : le corps bouge pendant toute la régénération, et tout le monde le voit (c'est fait par le serveur).

### Les effets
- **Les mains tremblent pendant le choix (G-205)** : pendant les secondes où l'on peut refuser la régénération, les épaules vibrent un peu (4 degrés au plus). On voit que l'énergie monte.
- **Genou à terre puis redressé (G-203)** : au début, le corps fléchit (penché, abaissé, un genou presque à terre), puis se redresse d'un coup, bras écartés, quand les jets jaillissent.
- **Une pose par style (G-201)** : Volcan cambré, tête très renversée ; Douce bras à peine levés ; Tourbillon bras à l'horizontale ; Colonne bras au ciel ; Supernova grand écart cambré ; Fracture par à-coups (quatre crans secs).
- **Assis (G-218)** : dans un siège, seulement les bras au ciel et la tête renversée ; les jambes ne bougent pas et il ne flotte pas.
- **Lévitation (G-204)** : avec Douce et Colonne, le corps s'élève de 1,5 stud pendant l'éruption, flotte, puis redescend avant la fin. L'AlignPosition est retiré à coup sûr (fin, nouvelle pose, retour au repos).
- **Il regarde ses nouvelles mains (G-202)** : à la fin, il lève les mains devant ses yeux, puis touche son visage, et revient au repos. Il ne peut repartir qu'après le geste (2,6 s).

### Réglages
| Réglage | Par défaut | Rôle |
|---|---|---|
| `Regeneration.Poses.ParStyle` | true | une pose par style (sinon la Classique pour tous) |
| `Regeneration.Poses.Tremblement` / `AmplitudeTremblement` | true / 4 | mains qui tremblent pendant le choix (degrés) |
| `Regeneration.Poses.GenouATerre` | true | flexion puis redressement |
| `Regeneration.Poses.Flexion` / `Baisse` | 22 / 0.6 | penché (degrés) et abaissé (studs) |
| `Regeneration.Poses.Assis` | true | pose assise dans un siège |
| `Regeneration.Poses.Levitation` / `HauteurLevitation` | true / 1.5 | lévitation de Douce et Colonne (studs) |
| `Regeneration.Poses.RegarderMains` / `DureeRegardMains` | true / 2.6 | geste de la découverte (secondes) |

### Technique
- `Config.Version = "7.5.3"`.
- Nouvelles fonctions de `TardisConfig` : `poseRegeneration` (pose de chaque style, et assise), `tremblement`, `poseDecouverte` (calculs purs, testés sans Roblox).
- `TardisSystemes` (serveur) : `poseRegeneration` refaite (articulations du torse et RootJoint, jeton de pose qui annule les étapes encore prévues d'une ancienne pose), `leviter`, `tremblerMains`, `gesteDecouverte`. Les vitesses d'avant la régénération sont gardées jusqu'à la fin du geste ; si une autre régénération commence pendant le geste, elles ne sont pas remplacées par 0.
- Aucune nouvelle action réseau.

### Simulations
- `outils/simulation/sim_v753.py` : **56 tests sur 56** (calculs des poses, du tremblement et du geste ; le vrai code du serveur : flexion puis redressement, Fracture par à-coups, pose assise, lévitation posée puis retirée, jeton qui annule une ancienne pose, retour au repos, tremblement arrêté, geste de la découverte, personnage sans torse ; sources). La simulation a corrigé un test (humanoïde factice sans « Sit »), pas le jeu.
- Toutes passent : **2944 vérifications**, analyse statique : 0 remarque.
