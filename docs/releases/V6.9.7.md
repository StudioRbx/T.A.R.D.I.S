# V6.9.7 — Corrections : TARDIS bloqué ou perdu

*Date : 03/11/2026*  
*Tag : `v6.9.7` (cible : `main`)*

Premier lot des propositions gardées (n° 141, 9, 24, 108 et 134 de [PROPOSITIONS_200.md](https://github.com/StudioRbx/T.A.R.D.I.S/blob/main/docs/PROPOSITIONS_200.md)). Vérifié par simulation (voir plus bas), pas encore en jeu.

### 1. Téléportation de poche en mode Silencieux (141)
- **Bug corrigé** : en mode Silencieux, la téléportation de poche faisait planter le script juste après avoir marqué le TARDIS « occupé ». Le TARDIS restait bloqué en démat jusqu'au redémarrage du serveur. Un client modifié pouvait le provoquer exprès.
- **Nouvelle option** `Config.Modes.Silencieux.SilenceABord` (désactivée par défaut) : quand elle est active, à bord aussi le moteur, le jukebox et l'ambiance se taisent pendant un voyage Silencieux. L'alarme reste audible.

### 2. Joueur visé qui quitte le jeu pendant le vol (9)
- Si le joueur choisi comme destination a quitté le jeu, ou n'a plus de personnage, au moment de la REMAT, le TARDIS **retourne à son lieu de départ** au lieu de rester dans le vortex. Le pilote lit par exemple « Amy a quitté le jeu : retour à Pont. ».
- TARDIS posé : le refus dit maintenant clairement « Amy a quitté le jeu » (au lieu de « joueur introuvable »).

### 3. Vol libre : pilote muet ou parti (24)
- Si le pilote n'envoie plus rien pendant **8 s** (figé, connexion perdue, client modifié), le TARDIS **se pose seul** en douceur au lieu de rester immobile dans les airs, occupé. Réglage : `Config.VolLibre.DelaiSansNouvelles` (0 = jamais).
- Si le pilote part **pendant que le TARDIS est invisible** (dans le vortex du vol libre), la cabine **se rematérialise d'abord sur place, avec son animation**, puis se pose. Avant, elle réapparaissait d'un coup au sol.

### 4. Chute dans le vide (108)
- Un membre de la C.A.T. qui tombe sous la limite de la carte est **rattrapé** : remonté à sa dernière position sûre (sur un sol), ou à défaut dans le TARDIS, puis il se régénère là, une seule fois. Avant, il pouvait se régénérer dans le vide en boucle.
- Le corps neuf d'une régénération après un corps disloqué n'est jamais replacé dans le vide.
- La dernière position sûre n'est réutilisée que s'il y a **encore un sol dessous** (le support a pu bouger ou disparaître) et si le joueur n'a pas déjà été rattrapé dans les 15 dernières secondes : sinon, directement dans le TARDIS. Le joueur est tenu une seconde sur place après le rattrapage. *(Correction issue de la revue indépendante du lot.)*

### 5. Portée des sons (134)
- Les sons de voyage s'entendent **fort près de la cabine, puis de moins en moins**, et plus du tout au-delà de 220 studs dehors (90 studs dans la salle de contrôle). Ça vaut aussi pour les Sound posés à la main dans `TardisAssets › Sons`, que Roblox faisait entendre à 10 000 studs. Réglage : `Config.PorteeSons`.

### Technique
- `TardisServeur` : `appliquerPortee`, garde dans `jouerSurPersonnage`, `nomsPartis`, `resoudreDestination(donnees, autoriserInterieur, repliSiParti)` (6e valeur : le message de repli), descente forcée lancée dans une tâche.
- `VolLibre` : `volLibre.derniereNouvelle`, surveillance du vol, rematérialisation avant la descente forcée ; `lancerDescente` déclarée avant son premier usage (erreur détectée par l'analyse statique pendant le développement).
- `TardisSystemes` : `positionsSures`, `pointDeSecours`, rattrapage sous `workspace.FallenPartsDestroyHeight + 30`.
- Clients : portée du son du vol libre, silence à bord (Ambiance, Signalisation).
- `Config.Version = "6.9.7"`, `Config.PorteeSons`, `Config.VolLibre.DelaiSansNouvelles`, `Config.Modes.Silencieux.SilenceABord`.

### Simulations
- `outils/simulation/sim_v697.py` exécute le vrai code : **24 tests sur 24**. Vol libre : pilote actif 10 s sans atterrissage ; muet 7 s, pas encore de descente ; muet plus de 8 s, descente puis TARDIS libéré ; pilote parti invisible, remat puis visible puis posé. Destinations : joueur présent, sans personnage, parti en vol (retour à « Pont »), parti posé (refus clair), inconnu. Poche en Silencieux : plus de plantage. Point de secours : sol présent, support disparu, rattrapage répété.
- Toutes les simulations précédentes passent toujours (analyse statique : 0 remarque).
- **Revue indépendante** (3 relecteurs, chaque problème vérifié par 2 sceptiques) : 2 problèmes confirmés sur la chute dans le vide, corrigés ; 1 commentaire de configuration remis à sa place ; 5 signalements réfutés.
