# V6.8.1 — Sauvegarde versionnée et accès sur mobile

*Date : 02/11/2026*  
*Tag : `v6.8.1` (cible : `main`)*

Modifications 25 et 8 de [PROPOSITIONS.md](https://github.com/StudioRbx/T.A.R.D.I.S/blob/main/docs/PROPOSITIONS.md). À tester en jeu.

### 1. Sauvegarde versionnée (modification 25)
- Nouveau ModuleScript **`TardisSauvegarde`** (ServerScriptService) : toutes les données passent par lui (état du TARDIS, réglages, rôles, statistiques, découvertes, préférences des joueurs).
- Chaque valeur est rangée dans une **enveloppe** `{ format, donnees, ecrit, version }` : le format pourra évoluer, une migration le mettra à jour à la lecture, et on sait quelle version du TARDIS a écrit chaque donnée.
- **Nouveaux magasins** `TardisSauvegarde_v2_<TARDIS>` et `TardisExtras_v2_<TARDIS>`. Les anciens (`…_v1_…`) **ne sont jamais modifiés ni effacés** : la première fois qu'une donnée manque dans le nouveau magasin, elle est recopiée depuis l'ancien (Output : « Sauvegarde migrée vers … »). Revenir à une version d'avant ne perd donc rien.
- **3 essais** pour chaque lecture et chaque écriture (le service DataStore échoue parfois), écritures par `UpdateAsync`.
- **Sécurité :** si une lecture échoue au démarrage, la donnée n'est **pas écrasée** pendant la session (avant, une lecture ratée pouvait remplacer une bonne sauvegarde par un état vide).
- Réglages : `Config.Sauvegarde.NomStore`, `AncienStore`, `NomStoreExtras`.

### 2. Accès sur mobile (modification 8)
- Sur un appareil **sans clavier**, deux boutons ronds au bord gauche : **T** (menu rapide) et **Y** (tablette), pour les pilotes. Ils se décalent quand le menu est ouvert.
- Un technicien (non pilote) a son propre bouton **Y · ingénierie**.
- Rien ne change sur ordinateur. `Config.BoutonsTactiles = false` les retire.

### Technique
- Nouveau module `TardisSauvegarde` ; `TardisServeur` et `TardisExtras` l'utilisent ; `TardisMenu` et `TabletteTechnicien` ont les boutons tactiles.
- `Config.Version = "6.8.1"`.
