# 1200 propositions (05/11/2026)

Après la V6.9.9 : 300 améliorations techniques (T), 300 graphiques (G), 300 des menus (M) et 300 changements de jeu (C).
Aucune ne reprend le premier tri des 200 ([PROPOSITIONS_200.md](PROPOSITIONS_200.md)) ni une fonction retirée ou refusée.
Chaque proposition a été écrite à partir du code actuel ; les doublons de sens entre familles ont été retirés et remplacés.

Effort : petit (quelques heures), moyen, gros (un chantier). La colonne « Choix » se remplit après le tri.
